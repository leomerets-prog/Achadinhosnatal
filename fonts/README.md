# Fontes

Os títulos usam Cormorant Garamond (Regular, 400). O destaque curto “neste Natal” usa Great Vibes (Regular, 400). Os arquivos WOFF são servidos pelo próprio site, sem requisições a serviços de fontes.

As duas famílias estão sob a licença SIL Open Font License 1.1, preservada nos arquivos `OFL-CormorantGaramond.txt` e `OFL-GreatVibes.txt`.

Fontes oficiais:

- https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
- https://github.com/google/fonts/tree/main/ofl/greatvibes

Os WOFF contêm os caracteres latinos, Latin Extended-A, pontuação e euro. A variante de Cormorant Garamond foi fixada no peso 400 antes do subset. Os acentos portugueses e as ligaduras foram preservados.
